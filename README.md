# Портфолио - Никита Ляпин

Современный сайт-портфолио с листающимися страницами.

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)
- Vercel для деплоя

## Установка и запуск

### Локальный запуск

**Самый простой способ (Windows):**
1. Дважды кликните на файл `start.bat` 
2. Откройте браузер и перейдите на `http://localhost:3000`

**Или через командную строку:**

**Вариант 1: Через Python (рекомендуется, не требует установки)**
```bash
python -m http.server 3000
```
Затем откройте в браузере: `http://localhost:3000`

**Вариант 2: Через PowerShell**
```powershell
.\start.ps1
```

**Вариант 3: Просто откройте index.html в браузере**
Просто дважды кликните на `index.html` - сайт откроется в браузере (но некоторые функции могут не работать из-за CORS)

**Вариант 4: Через npm (если установлен Node.js)**
```bash
npm start
```

## Деплой на Vercel

1. Установите Vercel CLI:
```bash
npm i -g vercel
```

2. Деплой:
```bash
vercel
```

Или подключите репозиторий к Vercel через веб-интерфейс.

## Структура проекта

```
├── index.html          # Главная страница (объединенная)
├── styles.css          # Стили
├── script.js           # JavaScript для листания страниц
├── package.json        # Конфигурация npm
├── vercel.json         # Конфигурация Vercel
├── face.JPG           # Фото для второй страницы

├── inst.svg           # QR код Instagram
├── st-sans/           # Шрифты ST Sans
└── BaystarScript*.otf # Шрифты BaystarScript
```
